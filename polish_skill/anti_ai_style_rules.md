# 反 AI 风规则（WRITE_SKILL Project 知识库）

> 本文档上传到网页端 WRITE_SKILL Project 作为知识库。Project 里的 AI 助手按本规则修订网文章节。

---

## 总原则

修改文风，不改情节、不改名词、不改人物。修订后的章节读起来像真人写的网文，不像 AI 写的。

---

## 句式硬规则

### ❌ 禁用

1. **强逻辑连接词**：「于是」「因此」「所以」「然后」「首先」「其次」「最后」
   - 例外：对白中口语化使用 OK
2. **三段并列结构**：「他既……又……还……」「她不仅……而且……更是……」
3. **超长句**：单句 ≥ 25 字 → 必须拆短
4. **客观全知解释**：「由于……的原因，主角……」
5. **过度精确描述**：「他用 0.3 秒挥出剑光」「他 7.5 分劲道挥出一拳」
6. **破折号 `——`**：任何场景一律禁用，是 AI 写作的高识别特征。需要停顿/转折/补充用「，」「。」「：」「（）」替代

### ✅ 推荐

1. **短句轰鸣**：70%+ 是 15 字以内的短句
2. **长短交替**：长句之后必跟短句
3. **每段最多 3 句**：关键场景 1 段 1 句
4. **主角视角 + 即时感官**：看到 / 听到 / 闻到 / 触到

---

## 心理描写硬规则

### ❌ 禁用套路表达

```
他感到非常愤怒
心如刀绞
激动得说不出话
五味杂陈 / 心里五味陈杂
不可置信
难以言喻
百感交集
万分紧张
```

### ❌ 慎用直接心理叙述

「他想道：……」式的大段使用 → 改成动作 / 表情 / 短促独白。

### ✅ 推荐用动作 / 表情 / 环境替代心理

| 错误（AI 风）| 正确（人类化）|
|---|---|
| 陆昭感到非常愤怒 | 陆昭的指节嘎吱作响。窗外那盏路灯，无端炸了。 |
| 她心如刀绞 | 她的指尖发凉。茶水洒了，她没注意。 |
| 他激动得说不出话 | 喉结上下动了一次。  半天，他才挤出一个字：「好。」|
| 林霜不可置信 | 林霜眨了眨眼。她的脑子，跟不上眼前的画面。|

---

## 对白硬规则

### ❌ 禁用

1. **过度文绉绉**：「实在是难以想象」「未免有些过于」
2. **AI 式礼貌**：「请问」「不知是否」（除非角色设定就是这样）
3. **解释性对白**：「我之所以这样做，是因为……」

### ✅ 推荐

1. **口语化**：「呵」「啧」「卧槽」「我去」「行吧」「算了」
2. **半句**：「这事儿……」「你别……」「等等！」
3. **角色个性化**：硬汉短话、活泼角色多语气词、阴沉角色言简意赅
4. **戛然而止 + 动作**：「『来。』他抬手一指。」

---

## 叙事硬规则

### ❌ 禁用结构化输出

- 列点（小说正文里不用「1. 2. 3.」）
- 「首先……其次……最后……」
- 「值得一提的是」「需要注意的是」
- 「综上所述」

### ✅ 推荐

1. **跳跃感**：场景切换不解释，直接跳
2. **信息密度起伏**：高潮密集、缓冲稀疏
3. **重要信息独占一段**：单段 1 句突出关键

---

## 打斗场面专项

### ❌ 禁用

1. **招式罗列**：「他先用 A，然后用 B，最后用 C」
2. **过度精确**：「剑光以每秒 50 米的速度飞出」
3. **理论解释**：「这一招的原理是……」

### ✅ 推荐

```
错误（AI 风）：
他挥剑刺向对方，剑光闪烁，速度极快，对方躲闪不及，被刺中喉咙倒地。

正确（人类化）：
剑光只是一线。
一线白。
对方的喉结，已经多了一个洞。
```

要点：感官冲击 + 短句节奏 + 局部特写 + 时间冻结感。

---

## 人类化痕迹（点睛之笔）

加入这些"小毛病"会让文字更像真人写的：

1. **重复**：「快。再快。还要更快。」
2. **残句**：「不对……这不对！」
3. **跳跃**：「他想说点什么。  没说。」
4. **错位修辞**：把不同感官混合（"她的笑声很烫"）
5. **极端短句**：单字成句、单段一字 - 「他笑了。  笑得很慢。」
6. **口头禅** / 角色专属表达（如硬汉爱说「行」、女主爱用「诶」）

---

## 修订流程（给 Project AI 的工作流）

收到用户粘贴的章节后：

1. **通读全文**，识别 AI 风密集区域
2. **优先改**：心理描写套路 + 长句 + 强逻辑词
3. **保留不改**：所有专有名词（人名/地名/装备/技能）、所有情节、所有人物关系、所有对白意思
4. **风格基准**：参照知识库中 external_style_samples/ 的句长 / 节奏 / 心理密度
5. **输出**：直接给修改后的全章正文，不解释、不评论、不加 meta 信息

## 自检（修订完成前确认）

- [ ] 每段是否 ≤ 3 句？
- [ ] 70%+ 的句子是否 ≤ 15 字？
- [ ] 是否还有「于是 / 因此 / 所以」等强逻辑词？
- [ ] 是否还有套路心理表达（心如刀绞 / 五味杂陈等）？
- [ ] **是否还有破折号 `——`？**
- [ ] 打斗场面是否短句轰鸣 + 局部特写？
- [ ] 对白是否口语化？
- [ ] 整体读起来像 AI 写的吗？

任一未通过 → 重改。

---

## 不要做的事

- ❌ **不改专有名词**（人名 / 地名 / 装备 / 技能保持原样）
- ❌ **不改情节**（不增不减事件）
- ❌ **不改人物关系**
- ❌ **不"翻译"成文学化语言**（这是网文，不是纯文学）
- ❌ **不擅自加创意**（不发挥，按规则执行）
- ❌ **不解释、不评论、不输出修改说明**
