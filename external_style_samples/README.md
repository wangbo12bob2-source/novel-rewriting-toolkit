# 外部网文风格样本库

## 用途

阶段三创作时，模型读取本目录下的样本作为 **few-shot 风格参考**，模仿真实优秀网文的句长、节奏、心理密度、对白方式 → **降低 AI 风识别率**。

## 文件命名

每个文件一段网文片段，命名格式：
```
<作品简称>_<场景类型>.md
```

例如：
- `quanqiugaowu_battle.md` ， 《全球高武》某场战斗
- `quanqiugaowu_dialog.md` ， 《全球高武》某段对白
- `chaoshenjixie_breakthrough.md` ， 《超神机械师》某次突破
- `guimizhizhu_psychology.md` ， 《诡秘之主》心理描写
- `wodedizi_facepunch.md` ， 《我的弟子全是女魔头》打脸场景

## 文件内容格式

每个文件 1-3 KB（约 500-1500 字），结构：

```markdown
# 样本：[来源] - [场景类型]

## 上下文
[用 1-2 句话说明这段在原书的位置和作用]

## 样本片段
> [粘贴网文原文片段，500-1500 字]

## 风格特点
- 句长：[平均句长 / 短句比例]
- 节奏：[快/慢/起伏]
- 心理描写密度：[高/中/低 + 用什么手法]
- 对白特点：[口语化/中二/简洁]
- 你想让 AI 学的关键点：[列 3-5 点]
```

## 推荐场景类型清单（建议每作品至少 3-5 个样本）

| 类型 | 学什么 |
|---|---|
| battle | 战斗场面节奏与冲击感 |
| breakthrough | 力量突破的爽感与情绪 |
| dialog | 角色对白的个性化与口语化 |
| psychology | 心理描写如何不套路 |
| facepunch | 打脸场景的递进与爆点 |
| daily | 日常场景的轻松感 |
| crisis | 危机降临的紧迫感 |
| reveal | 真相揭露的情绪转折 |

## 使用注意

1. **样本只用于 AI 学风格，不复用具体文字**：不要让 AI 直接抄样本里的句子
2. **样本本身有版权**：仅本地参考，不公开发布
3. **样本越多越好**：建议 5-7 部不同作品，每部 5-10 个样本，共 30-70 个样本
4. **样本要"对路"**：选你目标读者群熟悉的作品（番茄读者熟 LitRPG 类）
